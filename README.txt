CIRCLE STUDIO · THINK IN SHAPES

CARA MEMBUKA
1. Ekstrak seluruh ZIP ini.
2. Buka index.html dengan Chrome, Edge, Firefox, atau Safari.
3. Pilih EN atau ID untuk mengganti bahasa.

Versi index.html berdiri sendiri: latihan, diagram, ikon, dan tampilan sudah termasuk. Koneksi internet tidak diperlukan untuk latihannya. Tautan referensi past paper memerlukan internet.

24 misi mencakup keliling gabungan, jari-jari tersembunyi, daerah arsiran, perbandingan, berpikir mundur, dan soal campuran. Ada petunjuk bertingkat, pembahasan, dan ruang catatan.

Progres dan catatan disimpan oleh browser pada perangkat ini. Penyimpanan lokal mungkin dibatasi pada mode privat atau saat membuka file lokal. Jika browser membatasinya, latihan tetap bisa digunakan selama halaman terbuka.

Folder source berisi source code lengkap dari versi situs yang diterbitkan, termasuk dependensi yang dicatat di package-lock.json. node_modules, kredensial, cache, dan data browser tidak termasuk. Untuk mengubah program, gunakan folder source; index.html adalah versi siap pakai.

HOW TO OPEN
Extract the ZIP, then open index.html in a modern browser. The practice app works offline. Use EN / ID to switch languages. Progress is local to your browser and may be unavailable in private mode or under local-file storage restrictions. The source folder contains the complete application source.
